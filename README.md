The VMF repository for maps used in the [Postal 3 Ultrapatch](https://github.com/Kizoky/postal-iii-ultrapatch-angel) mod by [WhackJob Interactive](https://linktr.ee/WhackJob_Int).
Also includes 2 folders of Postal 3 Beta Maps stored as inspiration for Ultrapatch inclusions and a modified version of the P3 Alpha Town map, intended for use as an Ultrapatch tutorial area.
